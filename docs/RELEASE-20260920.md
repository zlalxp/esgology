# 회사 사이트 출시 준비 · 2026-09-20

## 승인 범위
사용자가 지정한 회사 소개 버전의 배포를 승인했다. `일은 계속되니까`와 출시 준비·AI 연결 준비 안내 문구를 지우고, 제품 화면을 최신 화면으로 바꾼다. 회사 소개의 영상형 첫 화면과 스크롤 구성을 유지한다. 제품 서비스의 데이터베이스·로그인·과금 설정은 변경하지 않는다.

## 공개 전 미디어 결정
기존 Infocz 참조 영상과 물속 이미지는 공개 사용 허락을 확인하지 못했으므로 출시 파일에 포함하지 않는다. 후보 A는 자체 Higgsfield 제작 14.2초 영상(`esgology-brand-film-v3-6.mp4`, 1920×1080, 10,057,833 bytes)이다. 제작 기록은 원본 기획 폴더의 `brand-film-validation.json` 및 `edit-six-scene-film.cjs`에 있다. 자체 생성 여섯 장면이며 Infocz·스톡 영상을 재사용하지 않은 것으로 기록돼 있다. 신규 생성·비용은 없다.

사용자는 해당 영상과 기존 승인된 사진 06(용수·수처리) 또는 08(공급망)의 조합을 검토 중이다. 이 선택 이전에는 main 병합·Pages 배포를 실행하지 않는다.

## 배포 경로
GitHub 저장소 `zlalxp/esgology`, 작업 브랜치 `feat/company-scroll-20260915`, 기존 PR 2. Pages는 main 브랜치의 루트 폴더를 서비스한다. main 병합이 공개 배포를 유발하므로 최종 미디어 결정·정확한 커밋의 검토·CI 통과 후 병합한다. 별도 호스팅이나 DNS 변경은 필요 없다.

## 검증
기존 QA는 24개 화면 크기·동작 줄이기·JavaScript 조합, 문의 창, 키보드 접근, 링크, 이미지와 외부 요청을 검사한다. 이번 문구 삭제에 맞춰 오래된 필수 문구 검사를 새 문구 및 삭제 문구 부재 검사로 바꾼다. 최신 제품 예시는 공개된 데모 화면을 사용할 때 ‘화면 예시’로 명시하고, 실제 고객 자료나 내부 계정 화면을 공개하지 않는다.

## 현재 상태
배포 전 준비 중. 미디어 선택, 최신 제품 화면, 최종 QA와 독립 검토, Pages 배포 및 공개 도메인 확인이 남아 있다. 이 문서는 출시 완료 증거가 아니다.
## 미디어 결정 후속
사용자가 기존 자체 영상의 품질을 이유로 사용하지 않기로 했다. 영상 파일은 복사·연결하지 않았다. 01 실내 사진을 첫 화면으로, 06 용수·수처리 사진을 마지막 영역으로 임시 배포할지, 새 영상 제작 전까지 회사 배포를 기다릴지 확인 중이다. 이전 후보 A는 선택 대상에서 제외한다. 새 영상 생성은 하지 않는다.


## 최종 미디어 승인
사용자가 '선택한 사진으로 먼저 배포'를 승인했다. 01 실내 사진을 첫 화면, 06 용수·수처리 사진을 마지막 영역에 적용했다. 참조 영상 태그와 재생 코드, 외부 배경 URL을 제거했다. 신규 영상은 생성하지 않았다. 출처·파일 해시는 release-media-provenance.json에 기록했다.

# 회사 소개 통합 시안 검증

## 실행 결과

Node 24 / Playwright / 실제 설치된 Edge의 headless 모드에서 로컬 HTTP로 실행했다. 다음 24개 조합이 모두 통과했다.

- 화면: 1440×960, 768×960, 375×812, 320×568, 1440×600, 1920×740.
- 자바스크립트: 활성화 / 비활성화.
- 동작 줄이기: 기본 / 줄이기.

확인 범위: 이미지 로딩, 가로 넘침, 첫 화면 제목과 내비게이션의 분리, Tab으로 본문 바로가기, 내부 HTML 응답, 제품 링크 대상, 문의 이메일, 대화상자 닫기 및 초점 복귀, 스크롤 3단계 전환과 최종 불투명도, 동작 줄이기 설정의 실시간 변경, 숨겨진 첫 화면 링크의 inert 처리, JS 비활성화 시 전체 단계 읽기, JS 오류·외부 자동 요청 없음. 실제 제품 외부 링크로 로그인하거나 고객 데이터를 처리하는 검사는 아니다.

스크립트 초기 실행의 보조 페이지 제품명 필수 조건은 잘못된 가정이어서 한국어 HTML 응답 검사로 수정했다. 장면 전환 중 캡처되는 문제는 최종 불투명도 확인을 추가하고 전체 검사를 다시 실행해 해결했다. 최종 검사 후 모바일 첫 화면, 데스크톱 제품 영역과 전환 완료 장면을 직접 확인했다.

## 검증 한계

24개 조합 통과는 WCAG 전체 준수나 모든 브라우저 지원을 의미하지 않는다. Safari·Firefox 및 실기기 터치, 고배율 확대, 느린 네트워크 성능은 별도 확인이 필요하다. PNG 4장 총 약 8.8MB의 최종 전송 최적화, 영상 교체, 실제 제품 화면 교체는 남아 있다. 이 결과로 전체 서비스 출시가 완료된 것은 아니다.

독립 검토 결과는 별도 REVIEW.md에 기록한다. 로컬 실행 결과와 화면 파일은 게시 대상 디렉터리 밖 QA_OUT에 보관한다.

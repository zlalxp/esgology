# 회사 소개 스크롤 시안 통합

2026-09-15 / 기준: 회사 소개 문구 브랜치 91111507

## 작업 범위

기존 v3.5 계열의 스크롤 시안과 별도로 생성한 산업 콘셉트 이미지를 회사 사이트 저장소에 연결한다. 기존 문구 브랜치와 원본 시안은 보존한다. 홈페이지의 HTML/CSS/JS, 자체 이미지, 검증 스크립트와 이 기록만 수정한다. 보조 페이지와 기존 styles.css는 유지한다.

## 완료 조건

- 320, 375, 768, 1440px 화면에서 가로 넘침 없이 읽을 수 있다.
- 스크롤 단계 이동, 키보드 탐색, 문의 창과 닫기, 내부 페이지 링크가 작동한다.
- 동작 줄이기 설정과 자바스크립트 비활성화 상태에서도 모든 설명을 읽을 수 있다.
- 외부 이미지·영상·폰트 요청 없이 동작한다. 제품 링크는 실제 ESGcheck 도메인으로 연결한다.
- 생성 이미지와 합성 제품 화면을 실제 시설·고객·서비스 실행 화면으로 오인하게 하지 않는다.
- 독립 코드 검토와 실제 브라우저 검사 결과를 남긴다.

## 출시 경계

디자인 검토 브랜치이다. 이 변경만으로 GitHub Pages를 배포하거나 DNS를 바꾸지 않는다. 회사 소개 영상은 사용자 요청대로 유료 영상 제작 후 교체할 예정이다. 제품 그림은 합성 데이터 설명용이며 실제 제품 화면으로 교체해야 한다. 이미지 출처 및 생성 조건은 image-provenance.json에 기록되어 있다.

현재 이미지 원본은 PNG 네 장, 총 약 8.8MB이다. 화면별 이미지 인코딩과 최종 서비스 화면 교체는 공개 전 성능·콘텐츠 확인 항목이다. 이 파일은 출시 승인이나 상표권 검토 결과를 의미하지 않는다.
